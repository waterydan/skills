# skills

Personal Codex skills.

## Available skills

Install skills from this repository with:

```sh
npx skills add https://github.com/waterydan/skills --skill <skill-name>
```

You can also list the skills the CLI discovers before installing:

```sh
npx skills add https://github.com/waterydan/skills --list
```

### code-planner

Create an implementation plan before code changes.

Install with:

```sh
npx skills add https://github.com/waterydan/skills --skill code-planner
```
